# Support

## I have a question about using Wizard

Start with the [documentation site](https://wizardw2.vercel.app/docs) —
installation, configuration reference, and a
[troubleshooting/edge-cases page](https://wizardw2.vercel.app/docs/troubleshooting/edge-cases)
covering the gotchas that come up most. If that doesn't answer it, ask in
[GitHub Discussions](https://github.com/Wizard-AIA/Wizard-w2/discussions).

## I found a bug

[Open an issue](https://github.com/Wizard-AIA/Wizard-w2/issues/new/choose)
using the bug report template. Include your OS, execution backend
(`docker`/`host`/`inprocess`), and model provider(s) — see the template for
the full checklist.

## I have a feature idea

Same place: [open an issue](https://github.com/Wizard-AIA/Wizard-w2/issues/new/choose)
with the feature request template, or start a
[Discussion](https://github.com/Wizard-AIA/Wizard-w2/discussions) first if
it's more of an open question than a concrete proposal.

## I found a security vulnerability

Do **not** open a public issue. See [SECURITY.md](SECURITY.md) for the
private reporting process.

## I want to contribute code or a skill

See [CONTRIBUTING.md](CONTRIBUTING.md) for the core repo, or
[Wizard-AIA/skills](https://github.com/Wizard-AIA/skills) if you're
contributing a `SKILL.md` to the community registry rather than code.

## Response times

This is currently a single-maintainer project (see
[MAINTAINERS.md](MAINTAINERS.md) / [GOVERNANCE.md](GOVERNANCE.md)). There's
no SLA — security reports get priority per `SECURITY.md`'s 48-hour
acknowledgement target; everything else is best-effort.
