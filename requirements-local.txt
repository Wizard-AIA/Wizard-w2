# The analysis toolkit, for running WITHOUT Docker.
#
#   uv pip install --system -r requirements.txt -r requirements-local.txt
#
# With `EXECUTION_BACKEND=host`, which is the default, generated code runs in a
# subprocess of *this* interpreter, so it can only
# import what is installed here. Nothing below is needed by the API server, and
# nothing below is needed at all when code runs in a container -- the sandbox
# image carries its own copies.
#
# You do not have to install all of it. The runtime is asked what it can import
# and the model is told exactly that, so a partial install means the agent is
# offered a smaller toolkit -- not that it writes code which then fails.

-i https://pkgs.safetycli.com/repository/nil-2662d/project/ai_data_analyst/pypi/simple/
